# 个人网站

在仓库根目录执行 `node site/server.js`，访问 http://127.0.0.1:8766/。本地 API `/api/projects` 与静态数据 `/projects.json` 提供相同的公开数据，服务仅监听本机。

`node site/build.js` 生成部署目录 `dist/`。构建脚本仅复制显式列出的文件；新增公开素材时，需同时更新构建清单和本地服务白名单。Vercel 配置使用此构建目录，其他仓库文件不应进入部署产物。部署前核对 Vercel 项目设置未覆盖仓库配置，并通过预览验证实际边界。`dist/` 是生成文件，不应手工编辑或提交。

素材：观测台图为原站样例图的脱敏局部；镜子图为历史平台预览；TimeBox 图为原站历史素材；GoGoWork 保留团队历史原型介绍，不展示旧图。构建保留原仓库中已公开的三份历史 PDF 的原路径。发布前核对图片与项目内容的授权和当前状态。
