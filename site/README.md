# 个人网站

在仓库根目录运行 `node site/build.js`，再运行 `node site/server.js`，访问 http://127.0.0.1:8766/。本地服务只读取生成的 `dist/`，不会暴露仓库根目录。修改源文件后需重新构建；可以通过 `PORT` 指定端口。

`site/projects.json` 是经过公开字段筛选的项目与模块目录；`site/media.json` 记录可公开的本地资源。构建脚本生成首页、项目索引及每个独立案例，并只复制明确列出的基础文件、媒体清单中的文件和三份历史 PDF。不要将内部审计字段、源路径、凭据或未获准素材加入公开清单。

视频静音、循环并提供播放控制，进入视口播放、离开暂停；手动暂停会保留。减少动态偏好或省流模式默认显示封面，可手动播放。内容与项目列表不依赖 JavaScript；搜索与筛选为渐进增强。

运行 `python3 tests/portfolio-smoke.py` 检查本地站点路由、素材、筛选、移动宽度及私有路径。可用 `PORTFOLIO_URL` 指向不同预览地址。`dist/` 是生成产物，不应手工编辑或提交。
